# 業務規則

## 結算流程

消費者選好商品後,系統依序套用「促銷折扣」與「優惠券」,算出最終結算金額。

## 已確認規則

1. **促銷折扣**:僅在結算日 = 促銷日期時生效,且只套用在對應品類。
2. **優惠券有效期**:結算日 ≤ 到期日即有效(含當天)。
3. **優惠券門檻**:以**促銷折扣後**金額判斷,≥ 門檻即成立。
4. **每次結算只能用一張優惠券**。
5. **金額**:一律使用 `Decimal`,最後四捨五入到小數 2 位。
6. **當前日期**:可由後台手動覆寫,也可切回系統真實日期。

## 測試案例(驗收用)

| 檔案 | 輸入摘要 | 預期輸出 |
| --- | --- | --- |
| `tests/fixtures/case_a.txt` | 電子品類 0.7 折促銷;明細:ipad*1、顯示器*1、啤酒*12、麵包*5;優惠券門檻 1000 折 200 | `3083.60` |
| `tests/fixtures/case_b.txt` | 無促銷;明細:蔬菜*3、餐巾紙*8;無優惠券 | `43.54` |

### case_a 計算過程

- 原價:ipad 2399.00 + 顯示器 1799.00 = 4198.00(電子品類)
- 促銷 0.7 折:4198.00 × 0.7 = 2938.60
- 其他品類:啤酒 12 × 25.00 = 300.00、麵包 5 × 9.00 = 45.00,合計 345.00
- 促銷後金額:2938.60 + 345.00 = 3283.60
- 優惠券(3283.60 ≥ 門檻 1000):3283.60 − 200 = **3083.60**

### case_b 計算過程

- 蔬菜 3 × 5.98 = 17.94、餐巾紙 8 × 3.20 = 25.60
- 無促銷、無優惠券:17.94 + 25.60 = **43.54**
